Project Description

An Intelligent Road Pothole Detection System Using Artificial Intelligence, Cameras, and Sensors is a smart system designed to detect potholes on roads while a vehicle is moving. The main purpose of the project is to improve road safety and help identify damaged roads more efficiently.

The system uses a camera installed on the vehicle to continuously capture images and video of the road. The captured images are processed using Computer Vision and Artificial Intelligence (YOLO) to detect potholes. The system can also use sensors, such as vibration sensors, to support the detection process and improve accuracy.

When a pothole is detected, the system records important information such as the image, detection time, confidence level, and GPS location. This information can then be sent to a mobile application, where users can view the detected potholes and their locations on a map.

Main Project Components

Camera: Captures images and video of the road.

YOLO and Artificial Intelligence: Detects potholes from the captured images.

Sensors: Help detect road vibrations and support pothole detection.

GPS: Records the location of each detected pothole.

Python: Runs the AI model and processes the captured data.

iPhone Application: Displays detected potholes and their information.

Database: Stores pothole images, locations, and detection information.
 Technologies Currently Used

Python — Programming language.

OpenCV — Used to operate the camera and process video.

YOLO / Ultralytics — Artificial intelligence model used for object detection.

PyTorch — Framework used to run the YOLO model.

NumPy — Used for data and image processing.

MacBook — Development and operating environment.
